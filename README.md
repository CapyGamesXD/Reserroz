# Reserroz

This is a less expensive alternative to the official Flipper Zero Wi-Fi Devboard. 

It is capable of running GhostESP and Wi-Fi Marauder*

The total cost for 2 units (shipping included) came out to <£30 each from JLCPCB - £5 less than the devboard. If they were manufactured manually, they would be significantly cheaper than the official version. It features an ESP32 S3 Mini 1 (double the cores than the official one, with Bluetooth!) as the main microcontroller chip.
